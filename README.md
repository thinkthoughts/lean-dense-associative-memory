# lean-dense-associative-memory

Lean formalization of energy functions, dynamics, and fixed-point structure in dense associative memory.

## Status

Initial scaffold. The first substantive checkpoint is reserved for equations and claims identified from Dmitry Krotov's CU Boulder Physics Colloquium, *Dense Associative Memory: physical systems for novel AI architectures* (September 16, 2026).

## Initial modules

- `LeanDAM.Basic` — state spaces, updates, and fixed points
- `LeanDAM.Energy` — energy functions
- `LeanDAM.Dynamics` — elementary orbit/dynamics definitions
- `LeanDAM.FixedPoint` — basic fixed-point lemmas

See `SPEC.md` for reading points and checkpoints.
